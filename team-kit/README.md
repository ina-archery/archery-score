# チーム共有キット（チーム代表用）

Archery Score で、**チームの選手同士だけ**が記録を見せ合うための仕組みです。

## 先に知っておくこと

- 記録は、**代表のGoogleアカウントの中のスプレッドシート**にだけ入ります。
- アプリの作者のサーバーはありません。**作者にも、他のチームにも、記録は見えません。**
- 送るのは、名前・日付・ラウンド・大会名・場所・順位・各回の点数・合計・10の数・Xの数だけです。的のどこに当たったかは送りません。
- 選手は、自分で「このチームに送る」をONにした場合だけ、記録が送られます。
- 代表がスプレッドシートを消すと、そのチームの記録は消えます。

## 代表の準備（最初に1回・10分ほど）

1. Googleドライブで、新しいスプレッドシートを作る（名前は「○○チーム スコア」など）。
2. メニュー「拡張機能」→「Apps Script」を開く。
3. 最初から入っているコードを全部消して、`team-sheet.gs` の中身を全部貼る。保存（💾）。
4. スプレッドシートに戻って、ページを読み込み直す。メニューに「チーム設定」が出る。
5. 「チーム設定」→「① 初期設定」を実行する。初回は「許可が必要です」と出るので、自分のアカウントで許可する（「詳細」→「安全ではないページに移動」を選ぶ場合があります。自分で貼ったコードなので問題ありません）。
6. 「設定」シートの **B1** に、チーム名を入れる。
7. Apps Script 画面に戻り、右上の「デプロイ」→「新しいデプロイ」。
   - 種類：**ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - 「デプロイ」を押して、出た **ウェブアプリのURL** をコピーする。
8. 「設定」シートの **B2** に、そのURLを貼る。
9. 「チーム設定」→「② 招待リンクを作る」を実行する。**B3** に招待リンクが入る。
10. その招待リンクを、選手に送る（LINEなど）。

## 選手の使い方

1. 招待リンクを開く（アプリが開く）。「このチームに入りますか？」→「入る」。
2. アプリの「設定」→「チームで共有」で、表示する名前を入れて「このチームに送る」をON。
3. 記録を保存すると、自動で代表のスプレッドシートに送られます。
4. 「チームの成績を見る」で、チームの自己ベストと最近の記録が見られます。

## 困ったとき

- **招待リンクが外に漏れた：** 「チーム設定」→「合言葉を変える」→「② 招待リンクを作る」。古いリンクは使えなくなります。選手に新しいリンクを配ります。
- **送れない：** 電波とリンクを確認。リンクを開き直して入り直すと直ることがあります。
- **スクリプトを直した：** 「デプロイ」→「デプロイを管理」→ 鉛筆 → 「新バージョン」で更新します（URLは変わりません）。

## 気をつけること

- 招待リンクは、**チームの人だけ**に渡してください。リンクを知っている人は、記録を送ることも見ることもできます。
- 「設定」シートと、スプレッドシート自体の共有は、代表だけにしておくのがおすすめです（選手に見せる必要はありません。選手はアプリで見ます）。
- 選手の名前などの個人情報は、代表の責任で扱ってください。
