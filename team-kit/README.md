# チーム共有（代表用・Googleフォーム方式）

Archery Score で、**チームの選手同士だけ**が記録を見せ合うための仕組みです。コードは要りません。

## 先に知っておくこと

- 記録は、**代表のGoogleアカウントの中のスプレッドシート**にだけ入ります。
- アプリの作者のサーバーはありません。**作者にも、他のチームにも、記録は見えません。**
- 送るのは、名前・日付・種別・ラウンド・大会名・場所・順位・1回目〜4回目の点数・合計・10の数・Xの数・IDだけです。的のどこに当たったかは送りません。
- 選手は、自分で「このチームに送る」をONにした場合だけ、記録が送られます。
- 招待リンクを知っている人は、チームの記録を送ることも見ることもできます。チームの人だけに渡してください。

## 代表の準備（最初に1回・10分ほど）

アプリの「設定」→「チームで共有」→「使い方（代表と選手）」にも、同じ手順が書いてあります。

1. 「フォームをコピー」を押して、開いた画面の「コピーを作成」を押します。
2. コピーしたフォームの右上「公開」を押して、もう一度「公開」を押します。
3. フォームの上の「回答」→「スプレッドシートにリンク」→「作成」を押します。
4. 開いたスプレッドシートで、「ファイル」→「共有」→「ウェブに公開」を押し、右の欄を「カンマ区切り形式（.csv）」にして「公開する」を押します。出たリンクをコピーします。
5. フォームの画面に戻り、右上の「回答者へのリンクをコピー」（鎖のマーク）で、フォームのリンクをコピーします。
6. アプリの「代表：チームを作る」の欄に、2つのリンクを貼り、チーム名を入れて「招待リンクを作る」を押します。出たリンクを、LINEなどで選手に送ります。

## 選手の使い方

1. 招待リンクを開きます。「このチームに入りますか？」で「入る」を押します。
2. アプリの「設定」→「チームで共有」で、表示する名前を入れて、「このチームに送る」をONにします。
3. 記録を保存するたびに、自動で代表のスプレッドシートに送られます。
4. 「チームの成績を見る」で、チームの自己ベストと最近の記録が見られます。

## 補足

- 同じ記録を直して保存し直すと、スプレッドシートに行が増えます。アプリの成績表示には、最新の分だけが出ます。
- 招待リンクが外にもれたときは、フォームの回答を止めて（フォームの「回答」→「回答を受け付ける」をオフ）、ウェブへの公開を止め、新しいフォームで作り直してください。
- 古い方式（Apps Script）は `team-sheet.gs` に残してありますが、通常は使いません。
